# 공간 지시서 예시 둘 — 모양만

> **모양만 — 이 물건·분위기·캐릭터를 후보로 쓰지 않는다.** 이 파일은 `2-4-stay-space.md` §4.2 틀로 지시서를 **다 쓴 뒤에만** 연다(§4.3 2번). 열면 참고 분위기·데이터 물건·소품·캐릭터에서 이 예시와 같은 낱말이 몇 개 겹치는지 세고, 셋 이상이면 그 항목들을 그 서비스 문서에서 다시 짓는다(§4.3 3번). 공간 에이전트에게는 넘기지 않는다.

두 예시는 일부러 성격을 반대로 골랐다 — 틀은 같고 내용은 서비스마다 다르다는 것을 보이려는 것이다. 두 서비스 모두 지어낸 예시앱이다.

| | 예시 1 — 작은 수족관 | 예시 2 — 놀이공원 안내 지도 |
|---|---|---|
| 그리기 방식 | 3D(코드로 만든 모형 — 원근 `Transform`과 `CustomPainter`, 패키지 없음) | 2D 손그림 지도(`CustomPainter`의 `Path`) |
| 캐릭터 | 있음 — 사용자의 분신 | 없음에 가까움 — 아주 작은 안내원 하나 |
| 공간 화면 | 첫 화면(로그인 뒤) | 첫 화면 |
| 이어받은 것 | 2-3 파격판의 3D 은유 | 2-3 파격판의 지도 은유 |
| 줄마다 붙은 근거 | 줄여 적었다 | 줄여 적었다 |

## 1. 예시 1 — 작은 수족관 (감정 기록 예시앱)

이 예시앱은 하루 한 번 그날의 기분을 한 줄과 감정 하나로 남기면, 쌓인 기록을 돌아보며 내 마음의 흐름을 알아차리게 해 주는 감정 기록 앱이다.

```markdown
# 공간 지시서 — 작은 수족관 (감정 기록 예시앱)

## 0. 이 공간
- 자리: S-01 홈(첫 화면, 로그인 뒤) — 목업 캔버스 S-01 줄
- 왜 값어치인가: 「지난 기록을 숙제처럼 읽지 않고, 내 마음이 쌓인 모습을 구경하듯 돌아보는 것」 — 근거: intent 「3」
- 어디를 볼지 고르는 장소인가: 사용자가 물고기(기록) 중 하나를 골라 다가가 들여다본다 — 근거: 화면 목록 홈의 주 행동
- 그리기 방식: 3D(원근 `Transform`과 `CustomPainter`로 그린 수조, 패키지 없음) — 근거: 2-3 파격판 「책상 위 작은 수족관」 이어받음
- 이어받는 것: 「4」 제목 서체·브랜드 면, 파격판 은유 「물고기 하나 = 기록 하나」 — 바꾸지 않음

## 1. 어떤 세계로 보일지
- 참고 분위기: 책상 위 작은 유리 수조를 옆에서 들여다보는 모습(구도), 비 오는 날 창가 스탠드 불빛(빛) — 근거: intent 「2」 여는 순간 「잠들기 전 침대에서」
- 시점: 정면에서 조금 위(약 15도), 손가락으로 좌우로만 조금 돌림
- 빛: 수조 위 스탠드의 따뜻한 빛 + 물속으로 퍼지는 옅은 물결 무늬, 그림자는 부드럽게 번짐
- 재질: 두꺼운 유리, 고운 모래 바닥, 매끈한 조약돌, 흔들리는 수초
- 모서리: 수조 모서리와 돌은 둥글게 — 손바닥만 한 장식품처럼
- 늘 도는 움직임: 물방울 오름, 수초 흔들림, 물결 무늬 흐름, 물고기가 천천히 헤엄침
- 공간 팔레트: 물빛 저채도(청록·모래·이끼) + 물고기만 감정별 중간 채도. 지금 고른 물고기 둘레 빛만 강조색
- 밀도: 가운데 물은 비우고 바닥·수초 사이를 소품으로 채움

## 2. 무엇으로 채울지
### 2-1 데이터를 맡은 물건
| 데이터 | 물건 | 물건 id | 상태별 | 근거 |
| 기록 하나 | 물고기 한 마리 | `fish-{기록 id}` | 이번 주: 위쪽에서 헤엄 / 지난 기록: 바닥 가까이 천천히 / 한 줄 메모 있음: 꼬리에 작은 방울 | 저장·조회 코드 entries |
| 감정 종류 | 물고기 모양과 색 | — | 기쁨·평온·지침·불안·화남 다섯 모양 | 기록 필드 mood |
| 연속 기록 일수 | 가운데 수초 높이 | — | 이어 쓸수록 자람, 끊기면 그대로(줄지 않음) | 기록 필드 date |
### 2-2 이야기 소품 (일부)
| 소품 | 이야기 | 누르면 |
| 바닥 조약돌 | 처음 기록한 날 놓인 돌 — 날짜가 새겨져 있다 | 가까이 — 돌 위 새김(장식) |
| 수조 옆 메모지 | 이번 달 가장 많이 고른 감정 한 낱말 | 가까이 |
| 작은 등대 장식 | 「요즘 어땠나」 돌아보기 화면으로 가는 길 | 가까이 — 등대 불빛 |
| 물 위 먹이통 | 오늘 아직 안 썼으면 뚜껑이 열려 있다 | 숨은 재미 |
| …(8~15개까지) | | |
### 2-3 숨은 재미
| 수조 유리를 두 번 두드림 | 물고기들이 잠깐 모였다 흩어짐 | 저장 없음 |
| 같은 감정 물고기를 길게 누름 | 같은 감정 물고기들이 한 줄로 헤엄침 | 저장 없음 |
### 2-4 빈 데이터일 때
물만 찬 빈 수조와 조약돌 하나, 분신이 먹이통을 들고 있음 → 글 층의 「오늘 기분 남기기」 주 버튼

## 3. 누가 사는지
- 캐릭터: 사용자의 분신 — 작은 잠수부 — 근거: intent 「3」 「내 마음을 들여다보는 느낌」
- 만드는 법: 둥근 도형 조합(헬멧·몸·물갈퀴), 가장 많이 고른 감정 색으로 헬멧 테두리
- 평소: 바닥을 걸으며 조약돌을 정리함, 가끔 물고기를 바라봄
- 물건을 고르면: 그 물고기 옆으로 헤엄쳐 가 손전등을 비춤
- 데이터에 따라: 기록이 쌓일 때마다 바닥 조약돌이 하나 는다

## 4. 누르면 무슨 일
| 지난 기록 물고기 | 고른 물고기가 반짝이고 짧은 진동 한 번 | 분신이 헤엄쳐 가고 카메라가 그 물고기로 다가감 | 비늘 무늬(그날 시간대), 꼬리 방울(메모 있음), 지느러미 모양(감정) | 아래에서 올라오는 판에 그날 한 줄과 감정(글 층) + 「기록 보기」 주 버튼 | 판을 내리거나 바깥을 누르면 카메라가 돌아옴 |

## 5. 어떻게 늘릴지
- 1개: 물고기 한 마리, 30개: 수조 가득, 넘치면 지난달 물고기는 「지난 달 어항」 작은 병으로 묶음
- 공간이 여럿: 계절마다 수조 배경이 바뀔 수 있음 — 처음엔 수조 하나, 같은 틀로 배경만 바꾸는 자리만 둠
- 새 데이터 종류가 생기면: 바닥 소품 하나를 더함

## 6. 그래도 지킬 것
- 글자: 날짜·한 줄 메모·감정 이름은 글 층
- 신호 자리: 지금 고른 물고기 둘레 빛만 강조색
- 동작 줄이기: 카메라 고정, 물고기·물방울 정지, 누르면 바로 판
- 대신 화면: 해당 없음(패키지 없는 코드 그림)
- 대체 경로: 공간 아래 「목록으로 보기」
- 화면 읽기·터치·스크롤: 물고기마다 이름표(「{날짜} {감정} 기록」), 차례는 날짜순. 돌리는 영역은 화면 높이의 절반 이하
- 진동·소리: 진동 — 물고기 고를 때 한 번 / 소리 — 효과음, 기본 꺼짐, 켜는 단추는 글 층 오른쪽 위
- 성능: 물고기 30마리 상한(넘치면 묶음), 수조 배경은 한 번 그려 남겨 씀, 다른 탭으로 가면 움직임 멈춤
- 새 기능 후보: 친구 수조 구경 가기(공유)
```

## 2. 예시 2 — 놀이공원 안내 지도 (챌린지 예시앱)

이 예시앱은 크리에이터가 만든 결과물과 만드는 방법을 공개하면 참가자가 따라 만들며 배우는 챌린지와, 상금을 건 콘테스트가 있는 서비스다. 다루는 분야가 다섯이다.

```markdown
# 공간 지시서 — 놀이공원 안내 지도 (챌린지 예시앱)

## 0. 이 공간
- 자리: S-01(첫 화면) — 목업 캔버스 S-01 줄
- 왜 값어치인가: 「길고 비싼 강의 대신 챌린지 한 개 단위로 짧게 직접 만들어 보는 것」 — 오늘 탈 놀이기구를 고르듯 챌린지를 골라 들어가는 재미 — 근거: intent 「3」
- 어디를 볼지 고르는 장소인가: 사용자가 구역(분야)·표지판(챌린지)·무대(콘테스트) 중 하나를 골라 다가간다 — 근거: 화면 목록 S-01의 주 행동, intent 「5」 플로우
- 그리기 방식: 2D 손그림 지도(`CustomPainter`의 `Path`) — 근거: 2-3 파격판 「놀이공원 안내 지도」 이어받음, 저가폰에서도 가벼운 쪽
- 이어받는 것: 「4」 제목 서체·글자 로고, 파격판 은유 「구역 = 분야, 놀이기구 표지판 = 인기 챌린지, 축제 무대 = 콘테스트」 — 바꾸지 않음

## 1. 어떤 세계로 보일지
- 참고 분위기: 입구에서 나눠 주는 접이식 종이 안내 지도(구도·재질), 색연필로 칠한 동네 축제 포스터(색) — 근거: 2-3 대담판 겉모습(종이 결 질감)
- 시점: 위에서 내려다본 평면 지도, 구역 경계는 굽은 길
- 빛: 그림자 없음 — 종이 위 인쇄처럼 평평하게, 접힌 자국만 옅게
- 재질: 접힌 자국이 있는 두꺼운 종이, 색연필 칠, 인쇄 잉크 선
- 모서리: 구역 경계는 손으로 그린 둥근 선, 표지판은 나무 팻말 모양
- 늘 도는 작은 움직임: 회전목마 깃발 펄럭임, 축제 무대 조명 깜빡임, 길 위 점선이 천천히 흐름(입구 → 고른 곳)
- 공간 팔레트: 분야마다 색연필 한 색(채도 중간, 명도 밝음) + 길·글자는 잉크색. 강조색은 고른 표지판 테두리와 입구에서 그곳까지의 길에만
- 밀도: 구역마다 빈 터를 남겨 표지판이 늘어날 자리를 둠

## 2. 무엇으로 채울지
### 2-1 데이터를 맡은 물건
| 데이터 | 물건 | 물건 id | 상태별 | 근거 |
| 분야 다섯 | 지도의 구역 다섯 | `zone-{분야}` | 챌린지 있음: 구역 이름 팻말 / 없음: 「공사 중」 울타리 | 저장·조회 코드 category |
| 인기 챌린지 | 구역 안 놀이기구 표지판(순위 · 참가 N명 줄 서기 팻말) | `ride-{챌린지 id}` | 자리보다 많으면 구역 이름 옆 「+N」 | 인기순 조회, 필드 participants |
| 진행 중인 콘테스트 | 지도 오른쪽 축제 무대(상금 깃발 · 남은 날) | `stage` | 마감 임박: 깃발에 남은 날 / 없음: 무대 막이 내려감 | 콘테스트 조회, 필드 prize·endsAt |
| 검색 | 입구 옆 안내소 | `info` | — | 화면 목록 S-31 |
### 2-2 이야기 소품 (일부)
| 소품 | 이야기 | 누르면 |
| 입구 매표소 | 「오늘 처음 오셨나요?」 — 첫 챌린지 추천 칸 | 가까이 — 매표소 창 |
| 구역 사이 벤치 | 지난주 완주한 사람 수가 새겨진 명판 | 가까이 — 명판 글(장식) |
| 분수대 | 새로 올라온 챌린지가 있으면 물이 솟음 | 숨은 재미 |
| …(8~15개까지) | | |
### 2-3 숨은 재미
| 광장 「놀이기구 뽑기」 기계를 누름 | 챌린지 하나가 무작위로 골라져 그 표지판까지 길이 그려짐 | 저장 없음 |
| 회전목마 깃발을 세 번 누름 | 깃발 색이 다섯 분야 색으로 차례로 바뀜 | 저장 없음 |
### 2-4 빈 데이터일 때
모든 구역에 「공사 중」 울타리, 무대 막이 내려감 → 글 층 「첫 챌린지 올리기」 주 버튼

## 3. 누가 사는지
- 캐릭터: 없음에 가까움 — 지도의 주인공은 고르는 사용자 자신이다. 안내소 창 안에 아주 작은 안내원 하나만(누르면 손을 흔듦) — 근거: intent 「2」 참가자가 「무엇부터 해야 할지 모를 때」 연다
- 만드는 법: 선 그림 몇 획
- 물건을 고르면: 안내원은 움직이지 않고, 입구에서 고른 곳까지 점선 길이 그려짐

## 4. 누르면 무슨 일
| 놀이기구 표지판 | 표지판이 살짝 흔들리고 강조색 테두리, 짧은 진동 한 번 | 입구에서 그곳까지 점선 길이 그려지며 지도가 그 구역으로 확대(`InteractiveViewer`) | 줄 서기 팻말의 참가자 수, 표지판 그림(결과물 미리보기), 순위 리본 | 챌린지 요약 카드가 아래에서 올라오는 판으로(글 층) + 「챌린지 보기」 주 버튼 | 판을 내리거나 지도 바깥을 누르면 확대가 풀림 |

## 5. 어떻게 늘릴지
- 챌린지가 늘 때: 구역마다 표지판 자리 상한, 넘치면 구역 이름 옆 「+N」 → 누르면 그 분야 목록
- 공간이 여럿: 분야마다 「구역 안 상세 지도」를 같은 틀로 더할 자리 — 처음엔 전체 지도 하나
- 새 분야가 생기면: 빈 터에 구역 하나를 더함

## 6. 그래도 지킬 것
- 글자: 챌린지 제목·참가자 수·상금은 글 층
- 신호 자리: 고른 표지판 테두리와 길만 강조색
```
