# 하네스 설계 노트

하네스 규칙의 설계 경위 모음입니다. 규칙 본문은 각 스킬·에이전트·rules에 있고, 여기에는 「왜 그렇게 정했나」만 쌓습니다.

이 파일은 `payload/` 밖이라 프로젝트로 복사되지 않습니다. 하네스를 고치는 사람만 읽는 자리입니다. `harness-diet`가 지시 문서에서 덜어 낸 경위·설계 이력을 옮겨 오는 곳도 여기입니다(`harness-auditor` 「이동 목적지」).

항목은 아래 모양으로 더합니다.

```
## <스킬·문서 이름> — <정한 것 한 줄>

출처: `payload/<파일 경로>` §<절>

> (지시 문서에서 덜어 낸 원문)

지금 규칙은 <어디에 무엇으로 남아 있는지>로 대신합니다.
```
